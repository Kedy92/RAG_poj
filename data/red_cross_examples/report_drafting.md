# Example: report drafting

This synthetic example represents a reporting workflow. It is not real Swedish Red Cross data.

A report writer needs to summarize what was promised in an application, what activities were completed, which indicators changed and what evidence supports the narrative. The information may be spread across applications, progress reports, monitoring files and financial summaries.

A RAG assistant can help by retrieving relevant passages, proposing a first draft and citing the source documents. The assistant should clearly show which information comes from which source, and a staff member should review the answer before it is used externally.

The most important design principle is traceability. A generated paragraph is only useful if the user can verify it against the original application or report.
