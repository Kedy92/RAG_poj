# Example: application classification

This synthetic example represents a previous humanitarian funding application. It is not real Swedish Red Cross data.

Program area: disaster preparedness and community resilience.
Country: Sweden and international partner countries.
Target group: local communities, volunteers and vulnerable households.
Donor type: institutional donor.
Expected outcomes: stronger local preparedness, faster response coordination and better reporting of community-level needs.

The application describes activities such as training volunteers, improving coordination routines, collecting needs assessments and preparing evidence for donor reporting. The document also mentions indicators related to number of trained volunteers, response time, number of households reached and quality of reporting.

For a RAG system, this application should be classified with metadata such as program area, geography, donor type, outcome area, indicators and reporting obligations. These labels would make it easier to find similar applications when writing a new proposal.

When asked what fields should be extracted, the system should identify programme area, country or region, donor type, target group, expected outcomes, indicators and reporting obligations.
